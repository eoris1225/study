① 핵심 정리 — 열역학

1. 열역학 제1법칙 (= 에너지 보존)

Q = ΔU + W   받은 열 = 내부 에너지 증가 + 기체가 외부에 한 일   W = PΔV (압력 일정)   P–V 그래프 아래 넓이 = 일

기호+ 일 때− 일 때판단하는 법
Q열을 흡수열을 방출ΔU와 W의 부호를 먼저 정하고 Q = ΔU + W로 결정
ΔU온도 상승온도 하강이상 기체: U ∝ T ∝ PV → 그래프에서 P×V 값이 커지면 ΔU > 0
W부피 증가(팽창): 기체가 일을 함부피 감소(압축): 기체가 일을 받음그래프에서 오른쪽으로 가면 +, 왼쪽이면 −

2. 네 가지 과정

과정조건Q = ΔU + W
등적W = 0Q = ΔU (열이 전부 온도로)
등압W = PΔVQ = ΔU + PΔV (열이 둘로 나뉨)
등온ΔU = 0Q = W (받은 열 = 한 일)
단열Q = 0ΔU = −W (팽창하면 식고, 압축하면 뜨거워짐)
헷갈렸던 것 ① — 그래프 구간별로 열을 흡수하나, 방출하나?
순서대로 정하면 돼요: ① W 부호(오른쪽 +, 왼쪽 −, 수직 0) → ② ΔU 부호(P×V가 커지나 작아지나) → ③ Q = ΔU + W.
• 등압 팽창: W +, PV↑ → ΔU + → Q + 흡수   • 등적 압력 감소: W 0, PV↓ → Q − 방출
• 등온 압축: W −, ΔU 0 → Q = W − 방출 → “일을 받은 만큼 열을 내보낸다” (일 받음 = 열 방출 크기 같음)
• 단열 압축: Q 0, W − → ΔU + (온도 상승). 단열 구간은 흡수도 방출도 아님!
헷갈렸던 것 ② — 같은 열 Q를 줄 때 등적 vs 등압 (188번 유형)
같은 Q를 주면 등적은 Q 전부가 ΔU, 등압은 일부가 일(W)로 빠져나가서 ΔU가 더 작음 → 온도는 등적이 더 많이 오른다.
“피스톤이 멈출 때까지 가열”처럼 준 열이 같다는 조건이 없으면 이 비교는 성립하지 않아요. 문제에서 무엇이 같은지(같은 Q? 같은 ΔT?)를 먼저 확인!

3. 순환 과정

처음 상태로 돌아오므로 ΔU(한 바퀴) = 0 → Q(순) = W(순) = 그래프로 둘러싸인 넓이. 시계 방향으로 돌면 기체가 외부에 일을 함(열기관).

헷갈렸던 것 ③ — “순환 과정에서 내부 에너지 변화는 0” (194번)
처음과 끝(한 바퀴 돈 뒤)을 비교하면 0이라는 뜻이에요. 도는 도중에는 구간마다 ΔU가 +도 되고 −도 돼요. “한 번도 변하지 않는다”는 틀린 말.

4. 열기관과 열효율

Q₁ = W + Q₂ (고열원에서 받은 열 = 한 일 + 저열원에 버린 열)   e = W/Q₁ = 1 − Q₂/Q₁   카르노: e = 1 − T₂/T₁ (T는 켈빈!)

헷갈렸던 것 ④ — 카르노 기관 vs “이상적인 열기관”
• 카르노 기관 = 가역 과정으로만 도는 가장 이상적인 열기관. 효율 = 1 − T₂/T₁ (같은 두 온도 사이에서 최대).
• 문제의 “이상적인 열기관”도 보통 카르노 기관을 뜻해요. 효율이 1이라는 뜻이 아님. 카르노도 Q₂ > 0 (저열원에 반드시 버림).
• Q₁과 W를 주면 Q₂ = Q₁ − W (그냥 빼면 됨). 이건 에너지 보존이라 어떤 열기관이든 성립.
• 효율 100% (Q₂ = 0) 열기관은 불가능 — 이걸 말해 주는 게 제2법칙.

5. 제1법칙 vs 제2법칙 / 엔트로피

제1법칙제2법칙
한마디로에너지의 양은 보존 (Q = ΔU + W)자연 현상의 방향 (저절로는 한쪽으로만)
말해 주는 것에너지가 새로 생기거나 사라지지 않음 → 제1종 영구 기관 불가능열은 저절로 고온 → 저온으로만 / 열효율 1인 열기관 불가능 / 엔트로피는 증가 → 제2종 영구 기관 불가능
구별 질문“에너지 계산이 맞는가?”“그 방향으로 저절로 일어나는가?”

ΔS = Q/T (열을 받으면 +, 잃으면 −, T는 켈빈). 고온 T₁ → 저온 T₂로 열 Q가 이동: ΔS(전체) = Q/T₂ − Q/T₁ > 0.
“전체 엔트로피는 감소하지 않는다” = 고립계 전체를 합하면 ΔS ≥ 0 (가역이면 0, 비가역이면 +). 한 물체의 엔트로피는 줄 수도 있지만(열을 잃은 쪽), 합치면 줄지 않음. 비가역 예: 열전도, 확산, 마찰, 자유 팽창.

① 핵심 정리 — 단진동 · 파동

6. 단진동 (용수철 진자)

F = −kx (복원력: 변위에 비례, 방향은 반대)   T = 2π√(m/k) (진폭과 무관)   단진자 T = 2π√(l/g)   T = 1/f

위치변위속력가속도·복원력운동 E탄성 퍼텐셜 E
평형점 (x = 0)0최대0최대 = E0
양 끝 (x = ±A)최대 A0최대 (평형점 쪽)0최대 = E
헷갈렸던 것 ⑤ — 왜 E = ½kA²?
용수철을 A만큼 늘리는 데 드는 힘은 0에서 kA까지 일정하게 커짐. 일 = F–x 그래프 아래 넓이 = 삼각형 = ½ × A × kA = ½kA². 이 일이 탄성 퍼텐셜 에너지로 저장돼요.
역학적 에너지 보존: ½mv² + ½kx² = ½kA² = ½mvmax² (어느 위치에서나 합이 같다)

7. 파동의 기본

v = fλ = λ/T   파동이 전달하는 것은 에너지 (매질은 제자리에서 진동만). 다른 매질로 들어가도 진동수 f는 그대로, 속력과 파장이 바뀜.

헷갈렸던 것 ⑥ — 파장 세기
횡파: 마루–마루, 골–골, 또는 같은 상태인 이웃 두 점 사이. 마루–골은 λ/2.
종파: 밀–밀, 소–소. 밀–소는 λ/2.
그래프 가로축이 위치(x)면 반복 간격 = λ, 시간(t)이면 반복 간격 = 주기 T.
탄성파 (역학적 파동)전자기파
매질매질이 꼭 필요 → 진공에서 전달 ✗매질 필요 없음 → 진공에서도 전달
예소리, 초음파, 지진파(P·S), 물결파, 줄의 파동빛(가시광선), 전파, 마이크로파, 적외선, 자외선, X선, 감마선
구별법“우주(진공)에서 전달되나?” → 되면 전자기파. 소리·초음파·지진파는 탄성파. 지진파 P파 = 종파(고체·액체·기체 통과), S파 = 횡파(고체만).

소리 속력: 고체 > 액체 > 기체, 공기는 온도가 높을수록 빠름(약 340 m/s). 반사: 고정단은 위상 반전(마루 → 골), 자유단은 그대로.

8. 소리의 간섭 (같은 위상의 두 음원)

경로차 = |S₁P − S₂P| → 반 파장(λ/2)이 몇 개?   짝수 개(0, λ, 2λ…) → 보강   홀수 개(λ/2, 3λ/2…) → 상쇄
주의: “λ의 1배니까 홀수”라고 세면 틀림. 반드시 λ/2 단위로 세기. 두 음원이 반대 위상이면 보강·상쇄가 서로 바뀜.

9. 정상파

마디–마디 = 배–배 = λ/2, 마디–옆 배 = λ/4. 마디는 전혀 안 움직임.
공명 실험(한쪽 닫힌 관, 수면을 내림): 공명 위치 L₁ = λ/4, L₂ = 3λ/4 → λ = 2(L₂ − L₁), v = fλ.

헷갈렸던 것 ⑦ — 정상파의 시간 (주기 T)
정상파를 만든 진행파의 주기 = T. 배가 가장 크게 휜 모양(t = 0) → T/4 뒤 줄 전체가 평평(변위 0, 속력 최대) → T/2 뒤 반대쪽으로 최대 → 3T/4 다시 평평 → T 처음 모양.
평평한 순간은 T/2마다, 최대로 휜 순간도 T/2마다 와요.
