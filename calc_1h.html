0. 미분 기계 — 모든 문제의 시작 (5분 · 이게 되면 나머지가 다 풀림)

개념쉬운 말 정리내 필기
도함수 $f'(x)$$f(x)$ 그래프의 기울기를 알려 주는 함수. $f'(2)$ = $x=2$ 인 점에서의 기울기.
$x^n$ 미분지수를 앞으로 내리고, 지수는 1 빼기: $x^3\to3x^2$, $x^2\to2x$, $x\to1$, 숫자 $\to0$
계수 · 합앞 숫자는 그대로 곱하고 항마다 따로: $(2x^3-5x+7)'=6x^2-5$
괄호 곱전개부터: $(x-1)(x+2)=x^2+x-2 \to 2x+1$
이런 문제는 이렇게
미분 4단계: ① 항 나누기 → ② 지수 내리기 → ③ 지수 −1 → ④ 숫자 항 지우기
예제 따라 풀기
$f(x)=2x^3-3x^2-12x+1$ 의 $f'(x)$ 와 $f'(2)$
① $2x^3$ → $6x^2$
지수 3 내리고 2×3=6, 지수 3−1=2
② $-3x^2$ → $-6x$
③ $-12x$, $+1$ → $-12$, $0$
$x$ 는 1, 숫자는 0
④ $f'(2)$ → $24-12-12=0$
$x$ 자리에 2 넣기
답: $f'(x)=6x^2-6x-12$, $f'(2)=0$
직접 풀기 0.
$f(x)=x^3-6x^2+9x+1$ 일 때 $f'(x)$ 와 $f'(2)$ 를 구하시오.

1. 함수의 증가와 감소 교과서 Ⅱ-2-03

개념쉬운 말 정리내 필기
증가 / 감소$x$ 가 커질 때 $f(x)$ 도 커지면 증가(그래프 ↗), 작아지면 감소(↘)
판정법$f'(x)\gt 0$ 인 곳 → 증가, $f'(x)\lt 0$ 인 곳 → 감소. 기울기 부호 = 오르막/내리막
증감표$x$ 줄에 $f'=0$ 인 값, $f'$ 줄에 $+/0/-$, $f$ 줄에 ↗ ↘. 삼차함수($x^3$ 계수 +)는 바깥 +, 사이 −
실수 전체에서 증가모든 $x$ 에서 $f'(x)\ge0$ → $f'$ 가 이차식이면 판별식 $D\le0$ (감소면 $f'\le0$: 최고차 음수 + $D\le0$)
이런 문제는 이렇게
증가/감소 구간: ① $f'(x)$ 인수분해 → ② $f'=0$ 인 $x$ → ③ 사이에 숫자 넣어 부호 → ④ $+$ 구간 / $-$ 구간
“항상 증가(감소)”, “$x_1\lt x_2$ 이면 $f(x_1)\lt f(x_2)$”: ① $f'(x)\ge0$ (또는 $\le0$) 세우기 → ② 이차식 최고차 부호 → ③ $\frac{D}{4}\le0$
헷갈리는 것 — 등호
증가 조건은 $f'(x)\gt 0$ 이 아니라 $f'(x)\ge0$ → 그래서 $D\le0$ ($D\lt 0$ 아님!). $x^3$ 은 $f'(0)=0$ 이어도 증가함수.
헷갈리는 것 — “$x_1\lt x_2$ 일 때 $f(x_1)\gt f(x_2)$”
말로 풀면 “항상 감소” → $f'(x)\le0$
예제 따라 풀기
$f(x)=x^3+ax^2+3x$ 가 실수 전체에서 증가할 때 $a$ 의 범위
① 미분 → $f'(x)=3x^2+2ax+3$
② 조건 → $f'(x)\ge0$ 이 항상 성립
아래로 볼록한 포물선이 $x$축 아래로 안 내려가야 함
③ 판별식 → $\frac{D}{4}=a^2-9\le0$
$b'^2-ac=a^2-3\cdot3$
답: $-3\le a\le3$
직접 풀기 1. [중단원 평가 Ⅱ-2 · 09번]
함수 $f(x)=ax^3+6x^2+(a-4)x+5$ 가 $x_1\lt x_2$ 인 임의의 두 실수 $x_1, x_2$ 에 대하여 $f(x_1)\gt f(x_2)$ 일 때, 실수 $a$ 의 최댓값을 구하시오.

2. 함수의 극대와 극소 교과서 Ⅱ-2-03

개념쉬운 말 정리내 필기
극대 / 극소극대 = 올라가다 내려가는 꼭대기 ($+\to-$), 극소 = 내려가다 올라가는 골짜기 ($-\to+$)
찾는 법$f'(x)=0$ 인 $x$ 를 찾고, 그 앞뒤로 부호가 바뀌는지 증감표로 확인
극댓값$f$ 값 ($f(\text{그 }x)$). $x$ 값이 아님!
조건 해석“$x=1$ 에서 극솟값 $-2$” → $f'(1)=0$, $f(1)=-2$ 두 식
극값을 가질 조건삼차함수: $f'(x)=0$ 이 서로 다른 두 실근 ⇔ $D\gt 0$ / 극값이 없다 ⇔ $D\le0$
이런 문제는 이렇게
극댓값·극솟값: ① $f'$ 인수분해 → ② 증감표 → ③ $+\to-$ 자리 $x$ 를 $f$ 에 넣기
극값 갖지 않을 조건: $f'(x)$ 의 $\frac{D}{4}\le0$
헷갈리는 것 — $f'=0$ 인데 극값 아님
$f(x)=x^3$: $f'(0)=0$ 이지만 부호가 $+\to+$ 라 극값 X. 부호 변화가 핵심.
예제 따라 풀기
$f(x)=2x^3-9x^2+12x$ 의 극댓값과 극솟값
① 미분 · 인수분해 → $f'(x)=6(x-1)(x-2)$
② 증감표 → $x\lt 1$: $+$, $1\lt x\lt 2$: $-$, $x\gt 2$: $+$
바깥 +, 사이 −
③ $x=1$ ($+\to-$) → 극댓값 $f(1)=2-9+12=5$
④ $x=2$ ($-\to+$) → 극솟값 $f(2)=16-36+24=4$
답: 극댓값 5, 극솟값 4
직접 풀기 2. [중단원 평가 Ⅱ-2 · 12번]
함수 $f(x)=3x^3+3kx^2+(3k+4)x-2$ 가 극값을 갖지 않도록 하는 자연수 $k$ 의 개수를 구하시오.

3. 그래프 · 닫힌구간의 최대와 최소 교과서 Ⅱ-2-04

개념쉬운 말 정리내 필기
그래프 그리기증감표 → 극대·극소 점 찍기 → $y$절편 $f(0)$ → 끝 모양(삼차 $x^3$ 계수 + 면 ↗로 끝)
닫힌구간 최대·최소후보 = 구간 안의 극값 + 양 끝값 $f(a), f(b)$. 전부 계산해서 비교
활용 (넓이·부피 최대)구하는 양을 한 문자 식으로 → 미분 = 0 → 범위 안 극대가 최대
이런 문제는 이렇게
최댓값·최솟값: ① $f'=0$ 인 $x$ 중 구간 안만 → ② 그 값 + 양 끝값 계산 → ③ 가장 큰/작은 것
헷갈리는 것 — 끝점
극댓값이 최댓값이라는 보장 없음. $x^3-3x$ 를 $[-2,3]$ 에서 보면 극댓값 2인데 최댓값은 끝점 $f(3)=18$!
예제 따라 풀기
$f(x)=x^3-3x$, $-2\le x\le3$ 에서 최댓값과 최솟값
① 후보 찾기 → $f'(x)=3(x+1)(x-1)=0 \Rightarrow x=\pm1$
둘 다 구간 안
② 값 계산 → $f(-2)=-2,\ f(-1)=2,\ f(1)=-2,\ f(3)=18$
끝점 2개 + 극값 2개
③ 비교 → 최대 18, 최소 −2
답: 최댓값 18, 최솟값 −2
직접 풀기 3. [중단원 평가 Ⅱ-2 · 18번]
닫힌구간 $[-4,2]$ 에서 함수 $f(x)=x^3+3x^2-9x+k$ 의 최댓값과 최솟값의 합이 12일 때, 상수 $k$ 의 값을 구하시오.

4. 방정식과 부등식에의 활용 교과서 Ⅱ-2-05

개념쉬운 말 정리내 필기
실근의 개수$f(x)=k$ 의 실근 개수 = $y=f(x)$ 그래프와 가로선 $y=k$ 의 교점 개수
문자 분리$x^3-3x-k=0$ → $x^3-3x=k$ 로 $k$ 를 한쪽에 모으기
삼차 세 실근극솟값 $\lt k\lt $ 극댓값. $f(x)=0$ 이 세 실근 ⇔ (극댓값)×(극솟값) $\lt 0$
부등식 항상 성립$f(x)\ge0$ ⇔ $f$ 의 최솟값 $\ge0$. $f(x)\gt g(x)$ 는 $h=f-g$ 로 만들어서 $h$ 의 최솟값 $\gt 0$
이런 문제는 이렇게
실근 개수 문제: ① $k$ 분리 → ② 왼쪽 함수 증감표 → ③ 그래프에 가로선 움직여 보기
부등식 문제: ① 한쪽으로 몰아 $h(x)$ → ② 주어진 범위에서 최솟값 → ③ 최솟값 조건
헷갈리는 것 — 범위 주의
“$x\ge0$ 인 모든 $x$” 이면 $x\ge0$ 안의 극값과 끝값 $h(0)$ 만 비교
예제 따라 풀기
$x^3-3x-k=0$ 이 서로 다른 세 실근을 가질 $k$ 의 범위
① 분리 → $x^3-3x=k$
② 극값 → 극댓값 $f(-1)=2$, 극솟값 $f(1)=-2$
$f'=3(x+1)(x-1)$
③ 가로선 → $-2\lt k\lt 2$ 에서 세 번 만남
답: $-2\lt k\lt 2$
직접 풀기 4. [중단원 평가 Ⅱ-2 · 21번]
$x\ge0$ 인 모든 실수 $x$ 에 대하여 부등식 $2x^3-11x^2-3x+a\gt 4x^2-27x$ 가 성립하도록 하는 정수 $a$ 의 최솟값을 구하시오.

5. 속도와 가속도 (미분) 교과서 Ⅱ-2-06

개념쉬운 말 정리내 필기
속도 · 가속도위치 $x(t)$ → 미분 한 번 = 속도 $v$, 두 번 = 가속도 $a$
운동 방향 전환$v=0$ 이고 부호가 바뀌는 순간
정지 · 속력정지 = $v=0$ / 속력 = $|v|$ (방향 없는 빠르기)
위로 던진 물체최고점에서 $v=0$
이런 문제는 이렇게
방향 바뀌는 시각: $v=x'(t)$ 인수분해 → $v=0$ 인 $t$ (부호 바뀌는지)
속력 최댓값: $v$ 를 완전제곱식으로 → 범위에서 $v$ 의 최대·최소 → 절댓값 큰 쪽
예제 따라 풀기
$x(t)=t^3-6t^2+9t$ 에서 운동 방향이 바뀌는 시각과 $t=3$ 에서의 가속도
① 속도 → $v=3t^2-12t+9=3(t-1)(t-3)$
② 방향 전환 → $t=1,\ 3$
$v=0$ 이고 부호 바뀜
③ 가속도 → $a=6t-12$, $a(3)=6$
답: $t=1, 3$ / 가속도 6
직접 풀기 5. [중단원 평가 Ⅱ-2 · 22번]
수직선 위를 움직이는 점 P의 시각 $t$ 에서의 위치 $x$ 가 $x=\frac13t^3-3t^2+8t$ 일 때, $2\le t\le6$ 에서 점 P의 속력의 최댓값을 구하시오.

6. 부정적분 — 미분을 거꾸로 교과서 Ⅲ-1-01

개념쉬운 말 정리내 필기
부정적분“미분해서 $f(x)$ 가 나오는 함수”. $F'(x)=f(x)$ 이면 $\int f(x)dx=F(x)+C$
공식$\int x^n dx=\frac{x^{n+1}}{n+1}+C$ — 지수 1 더하고 그 수로 나누기. $\int k\,dx=kx+C$
$+C$미분하면 상수가 사라지니까 원래 상수 모름 → 꼭 $+C$. 조건 $f(0)=3$ 등으로 $C$ 결정
접선의 기울기“곡선 위 점 $(x,y)$ 에서 접선의 기울기가 $g(x)$” = $f'(x)=g(x)$ → 적분
이런 문제는 이렇게
$f'$ 주고 $f$ 값 묻기: ① 적분 ($+C$) → ② 주어진 값 넣어 $C$ → ③ 원하는 $x$ 대입
헷갈리는 것 — 순서에 따라 $C$
$\frac{d}{dx}\int f(x)dx=f(x)$ (C 없음) / $\int\frac{d}{dx}f(x)\,dx=f(x)+C$ (C 있음)
예제 따라 풀기
$f'(x)=6x^2-2x$, $f(0)=3$ 일 때 $f(1)$
① 적분 → $f(x)=2x^3-x^2+C$
$6\cdot\frac{x^3}{3}=2x^3$
② $C$ 구하기 → $f(0)=C=3$
③ 대입 → $f(1)=2-1+3=4$
답: 4
직접 풀기 6. [중단원 평가 Ⅲ-1 · 05번]
함수 $f(x)$ 에 대하여 $f'(x)=3x^2-4x$ 이고 $f(0)=2$ 일 때, $f(1)$ 의 값은?

7. 정적분 교과서 Ⅲ-1-02

개념쉬운 말 정리내 필기
계산법$\int_a^b f(x)dx=F(b)-F(a)$ — 부정적분에 위끝 넣은 값 − 아래끝 넣은 값 (답은 숫자)
성질$\int_a^a=0$, $\int_b^a=-\int_a^b$, $\int_a^c+\int_c^b=\int_a^b$ (구간 이어 붙이기)
$\int_{-a}^{a}$홀수 차수($x, x^3$) 항은 0, 짝수 차수·상수항은 $2\int_0^a$
절댓값안이 0 되는 점에서 쪼개고, 음수 구간은 $-$ 붙이기
$\int_a^x f(t)dt$$x$ 로 미분하면 $f(x)$, $x=a$ 넣으면 0
$f(x)=\cdots+\int_0^1 f(t)dt$$\int_0^1 f(t)dt$ 는 숫자 → $k$ 로 두고 $k$ 를 구함
이런 문제는 이렇게
$\int_a^x f(t)dt=g(x)$ 꼴: ① 양변 미분 → $f(x)=g'(x)$ ② $x=a$ 대입 → $g(a)=0$ (숨은 조건)
정적분이 들어간 함수: ① $\int f=k$ 로 두기 ② $f$ 를 $k$ 로 표현 ③ 다시 적분해서 $k$ 방정식
예제 따라 풀기
$\int_1^x f(t)dt=x^2-3x+2$ 일 때 $f(4)$
① 양변 미분 → $f(x)=2x-3$
$\frac{d}{dx}\int_1^x f(t)dt=f(x)$
② 대입 → $f(4)=5$
③ 검산 → $x=1$: 좌변 0 = 우변 $1-3+2=0$ ✓
답: 5
직접 풀기 7. [중단원 평가 Ⅲ-1 · 13번]
다항함수 $f(x)$ 가 모든 실수 $x$ 에 대하여 $\int_0^x f(t)dt=x^3-2x$ 를 만족시킬 때, $f(4)$ 의 값을 구하시오.

8. 넓이 교과서 Ⅲ-2-01

개념쉬운 말 정리내 필기
곡선과 $x$축넓이 $=\int_a^b|f(x)|dx$ — $x$축 아래 부분은 $-$ 붙여서 양수로
두 곡선 사이$\int_\alpha^\beta(\text{위}-\text{아래})dx$. $\alpha, \beta$ = 교점 (두 식 같다고 놓고 풀기)
꿀공식이차함수 & 직선(또는 이차끼리)이 $x=\alpha,\beta$ 에서 만나면 $\frac{|a|}{6}(\beta-\alpha)^3$ ($a$ = 위−아래의 $x^2$ 계수)
이런 문제는 이렇게
넓이 3단계: ① 교점 구하기 ② 사이에 숫자 하나 넣어 누가 위인지 ③ (위−아래) 적분
헷갈리는 것 — 부호
$\int_0^3(x^2-3x-4)dx$ 를 그대로 계산하면 음수 → 넓이는 반드시 양수. 그래프 대충이라도 그리기!
예제 따라 풀기
$y=x^2$ 과 $y=2x+3$ 으로 둘러싸인 넓이
① 교점 → $x^2=2x+3 \Rightarrow x=-1,\ 3$
$(x-3)(x+1)=0$
② 위/아래 → $x=0$: 직선 3 > 곡선 0 → 직선이 위
③ 적분 → $\int_{-1}^{3}(2x+3-x^2)dx=\frac{32}{3}$
꿀공식: $\frac16\cdot4^3=\frac{32}{3}$ ✓
답: $\frac{32}{3}$

9. 속도와 거리 (적분) 교과서 Ⅲ-2-02

개념쉬운 말 정리내 필기
위치위치 = 처음 위치 + $\int_0^t v\,dt$ (원점 출발이면 처음 위치 0)
위치의 변화량$\int_a^b v\,dt$ — 앞뒤로 움직이면 상쇄됨
움직인 거리$\int_a^b|v|\,dt$ — $v=0$ 에서 쪼개서 전부 양수로 더함
$v$-$t$ 그래프넓이 = 거리 (축 위 +, 아래 − 는 위치 변화에서만)
원점 다시 통과위치 $\int_0^t v\,dt=0$
이런 문제는 이렇게
거리 문제: ① $v=0$ 인 $t$ 찾기 ② 그 점에서 쪼개기 ③ 각 구간 절댓값 더하기
헷갈리는 것 — 위치 vs 거리
갔다가 돌아오면 위치 변화는 0이어도 움직인 거리는 0이 아님
예제 따라 풀기
$v(t)=3t^2-6t$, 원점 출발. $t=3$ 에서의 위치와 $0\sim3$ 동안 움직인 거리
① 위치 → $\int_0^3(3t^2-6t)dt=\big[t^3-3t^2\big]_0^3=0$
원점에 돌아옴
② 방향 → $v=3t(t-2)$: $0\lt t\lt 2$ 뒤로, $t\gt 2$ 앞으로
③ 거리 → $\int_0^2(6t-3t^2)dt+\int_2^3(3t^2-6t)dt=4+4$
답: 위치 0, 거리 8
