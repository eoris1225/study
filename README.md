# 엔트로피의 황혼과 공명의 노래 (Twilight of Entropy)

물리학 교재(열역학 제1법칙 ~ 정상파)를 조작형 미니게임으로 익히는 다크 판타지 웹 RPG.
빌드 과정 없이 `index.html`을 열면 바로 실행되는 정적 사이트입니다.

가로 화면 횡스크롤 액션으로 진행하며, 몬스터·보스를 만나면 물리 미니게임 전투가 시작됩니다.
조작: ←/→ 이동, Space 점프 (모바일은 화면 버튼, 가로 모드).

- `js/art.js` — 캐릭터·몬스터·배경 그래픽
- `js/world.js` — 횡스크롤 월드(이동, 점프, 수집, 이벤트)
- `js/core.js` — 세이브, 대화, 야영지, 마도서, 캐릭터 커스텀
- `js/minigames.js` — 미니게임 12종
- `js/ch1.js` ~ `js/ch7.js` — 챕터별 스토리·기믹·교재 정리 노트 (새 챕터는 파일을 추가하고 `index.html`에 등록)

## 실전 문제집

`docs/`의 수준별 평가 PDF 문항 123개를 `problems/`에 문항별 이미지로 잘라 넣고, `js/problems.js`에 정답·힌트·단계별 풀이를 담았습니다. 게임 안의 📝 버튼으로 엽니다.

- `js/scenes.js` — 만져 보는 애니메이션 장면, 공식 관계 탐구
- `js/lessons*.js` — 개념 수업
- `js/workbook.js` — 문제집 화면
