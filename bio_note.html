효모의 알코올 발효 실험

퀴네 발효관 A~D에 용액을 넣고 시간을 흘려 보내요. 맹관부에 모이는 기체로 효모가 어떤 당을 발효하는지 알아봐요.

여긴 내 실험실! 발효관 4개에 용액을 넣고 시간을 돌려 봐. 효모가 산소 없이 당을 분해하면 맹관부 위쪽에 기체가 모여. 먼저 예상하고, 실험하고, KOH로 기체의 정체까지 밝혀 보자!

실험 준비

발효관 구조

맹관부: 한쪽 끝이 막힌 긴 관. 용액을 가득 채우면 공기(산소)가 없는 조건이 되고, 발생한 기체가 위쪽에 모여 부피를 잴 수 있어요.

솜마개: 외부 미생물·먼지가 들어오는 것을 막아요.

넣는 용액

A 포도당 20mL + 물 15mL
B 포도당 20mL + 효모액 15mL
C 설탕 20mL + 효모액 15mL
D 갈락토스 20mL + 효모액 15mL

먼저 예상해 보기 예측

실험하기 직접 조작

35°C

온도를 정하고 실험 시작을 눌러요. 효모가 가장 잘 일하는 온도는 30~40°C 정도예요.

결과 해석과 의의

발효관기체 발생이유
A 포도당 + 물없음효모가 없음 → 대조군
B 포도당 + 효모가장 많음포도당을 바로 해당 과정에 이용
C 설탕 + 효모많음 (B보다 약간 느림)설탕(이당류)을 효소로 포도당 + 과당으로 분해한 뒤 이용
D 갈락토스 + 효모거의 없음효모가 갈락토스를 거의 이용하지 못함
  1. 효모는 산소 없이 당을 분해해 CO2를 만든다 → 맹관부는 공기가 차단된 무산소 조건이므로 이 기체는 알코올 발효의 산물이다. (C6H12O6 → 2C2H5OH + 2CO2 + 2ATP)
  2. 기체가 CO2임을 확인: KOH(수산화 칼륨) 용액을 넣으면 KOH가 CO2를 흡수해 맹관부의 기체 부피가 줄어든다.
  3. 에탄올 생성 확인: 솜마개를 열면 술 냄새가 난다 → 또 다른 산물인 에탄올.
  4. A는 대조군: 효모가 없으면 기체가 안 생기므로, 기체 발생의 원인이 효모임을 증명한다. (조작 변인: 효모의 유무·당의 종류, 통제 변인: 당 용액 양, 온도, 시간)
  5. B·C·D 비교: 효모가 이용할 수 있는 당의 종류가 다르다 → 효모의 효소는 기질 특이성이 있어 맞는 기질(당)만 분해할 수 있다.
  6. 온도·끓인 효모: 너무 낮으면 느리고, 너무 높거나 끓이면 효소(단백질)가 변성되어 기체가 거의 생기지 않는다 → 발효는 효소 반응이다.
  7. 생활 속 의의: 빵이 부푸는 것은 CO2, 술은 에탄올 때문 → 알코올 발효를 이용한 대표적인 예.
