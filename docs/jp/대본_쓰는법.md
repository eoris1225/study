# 대본 쓰는 법

`docs/jp/대본.txt`를 고친 뒤, 아래 명령으로 게임에 넣으면 돼요. 손으로 하기 귀찮으면 고친 파일만 보내 줘요. 그다음은 제가 할게요.

```
node tools/jp_script.js build     # 대본.txt → 게임(js/jp/story.js)
node tools/jp_script.js export    # 지금 게임 대본 → 대본.txt (덮어씀, 주의)
```

형식이 틀리면 `build`가 **몇 번째 줄을 고치면 되는지** 알려 주고 멈춰요. 게임은 망가지지 않아요.

---

## 1. 기본 줄

```
=== EP1. 제목 | 메뉴에 보일 한 줄 설명
```
이 줄이 에피소드 하나의 시작이에요.

```
나: 유나의 속마음(내레이션)
유나: 대사
유나 [표정/동작]: 대사
스즈 [smile/nod]: 대사
엄마: 목소리만 나오는 인물
```
- 말하는 사람은 **나, 유나, 스즈, 엄마, 아빠, 하나, 미야코, 선생님, 반친구, 선배아빠, 하루토** 중에서 골라요.
- 선택지의 `맞으면:` / `틀리면:` 줄도 `미야코: …`, `스즈 [smile/]: …`처럼 앞에 이름을 쓰면 그 사람이 말해요. 안 쓰면 스즈가 말해요.
- `[표정/동작]`은 유나·스즈만 쓸 수 있어요. 둘 다 생략해도 되고, 하나만 써도 돼요. 예: `[cry/]`, `[/hug]`
- `#`으로 시작하는 줄은 메모예요. 게임에 안 나와요.
- `<b>굵게</b>`를 쓰면 노란 강조가 돼요.
- 일본어는 「」 안에 써요. 다음 업데이트부터는 `「おじゃまします|실례하겠습니다」`처럼 `|뒤에 뜻`을 붙일 수 있어요. 그러면 자막 아래에 한글 발음이 자동으로 붙고, 누르면 뜻과 일본어 음성이 나와요. 한자가 들어가면 `「山下{やました}|산 아래」`처럼 `{읽기}`를 붙여 줘요.

## 2. 연출 명령 (@로 시작)

| 명령 | 예시 | 설명 |
|---|---|---|
| `@배경` | `@배경 shrine 밤` | 장소를 바꿔요. 페이드도 같이 돼요. `밤`은 선택이에요 |
| `@제목` | `@제목 EP2. 세일러복 / 4월 · 개학날` | 화면 가득 장 제목이 떠요 |
| `@장소` | `@장소 2학년 B반 교실 · 점심시간` | 왼쪽 위에 📍 장소 표시 |
| `@카메라` | `@카메라 close` | 카메라 앵글 (아래 목록) |
| `@효과` | `@효과 sakura` / `@효과 없음` | 화면 효과 |
| `@표정` | `@표정 스즈 blush` | 대사 없이 표정만 바꿀 때 |
| `@동작` | `@동작 유나 hug` | 대사 없이 동작만 |
| `@위치` | `@위치 스즈 0 0 4 3.14` | 순간이동: x y z 바라보는방향(라디안) |
| `@걷기` | `@걷기 스즈 1.2 4` | 걸어가기: x z (방향은 선택) |
| `@소품` | `@소품 유나 gift` / `@소품 유나 gift 끔` | 손에 들기 / 내려놓기 |
| `@흔들림` | `@흔들림 0.8` | 화면 흔들림 세기 |
| `@소리` | `@소리 bell` | 효과음 |
| `@대기` | `@대기 1200` | 1.2초 기다리기 |
| `@문제` | `@문제 4-1` | 교과서 문제 세트를 풀어요 (목록은 아래) |
| `@조명` | `@조명 장마_오후` | 빛 분위기 (목록은 아래). 뒤에 (설명)을 붙여도 돼요 |
| `@호흡` | `@호흡 800` | 글자 없이 0.8초 쉬기 |
| `@텍스트속도` | `@텍스트속도 느림` | 느림 / 보통 / 빠름 |
| `@글자떨림` | `@글자떨림 강함` | 다음 대사 한 줄만 글자가 떨려요 (약함 / 강함) |
| `@수첩` | `@수첩 연하장_인사말_앞면세로쓰기` | 생존 수첩에 항목 추가 |
| `@플래시` | `@플래시 흰색 빠름` | 화면이 번쩍 (흰색·검은색·빨간색, 빠름·느림) |
| `@시점` | `@시점 암전_파형` / `@시점 복귀` | 화면 가장자리가 어두워지고 심장 박동 같은 파동. 배경이 바뀌면 자동으로 꺼져요 |
| `@노이즈` | `@노이즈 강함` / `@노이즈 없음` | 지지직 화면 + 이명 (약함 / 강함) |

## 3. 선택지

**시험 선택지**: 정답이 있어요. 맞으면 호감도 +3, 틀려도 +1이에요. 틀려도 정답과 해설이 나오고 이야기는 그대로 진행돼요. 틀린 문제는 '놓친 문제'에 모여요.
```
@선택 집 안으로 들어서며 하는 인사말은?
  * 「おじゃまします」          ← * = 정답
  - 「いただきます」
  - 「おやすみなさい」
  해설: 교과서 내용 (📘로 표시돼요)
  맞으면: 스즈 대사
  틀리면: 스즈 대사 (다정하게)
```

**마음 선택지**: 정답이 없어요. 뭘 골라도 좋은 장면이 나오고 호감도 +2예요.
```
@마음선택 스즈 머리를 어떻게 묶어 줄까?
  - 반만 묶고 리본 | blush/shy | 스즈 대사
  - 하나로 높게 | happy/nod/pat | 스즈 대사      ← 세 번째 칸 = 그때 유나가 하는 동작
  배움: 교과서 한 줄 (📘)
```

## 4. 쓸 수 있는 값

- **배경** (뒤에 `밤`이나 `장마`를 붙일 수 있어요. 바깥 배경에 `장마`를 붙이면 비가 내려요)
  - genkan (현관), room (다다미방, 고타쓰), class (교실), club (가루타부), school (운동장·교사)
  - shrine (신사), festival (축제·등불, 밤 추천), street (벚꽃길), kyoto (교토 오층탑), hospital (병실), airport (출국장), stadium (고시엔 구장)
- **카메라**
  - two (투샷), wide (멀리), sky (하늘)
  - suzu (유나 어깨 너머로 스즈), onna (스즈 어깨 너머로 유나)
  - close (스즈 클로즈업), closeo (유나 클로즈업)
  - 틸트 (화면 기울이기), 줌인 느림 / 줌인 빠름, 줌아웃
- **효과**: sakura, snow, fireworks, firefly, confetti, beans, rain, rain_heavy, 없음
- **조명**: 아침햇살, 정오햇살, 오후햇살, 오후실내, 오후노을_시작, 오후노을, 오후노을_저채도, 저녁노을_어스름, 저녁실내, 밤달빛, 벚꽃역광, 장마_오후, 장마_역광, 장마_저녁, 병원형광등, 밤형광등, 체육관빛, 축제등불, 불꽃빛, 겨울아침, 겨울오후, 겨울저녁, 겨울흐림, 고타쓰
- **스즈 표정**: n, blink, happy, smile, lol, teeth, grin, smug, worry, sad, cry, oh, wow, shout, pout, mad, blush, shy, think, sleepy, meh
- **유나 표정**: n, blink, smile, lol, happy, grin, smug, oh, wow, shout, sad, cry, worry, ugh, meh, mad, pout, shy, think, sleepy
- **동작**
  - 기본: idle, talk, nod, shake, tilt, listen, think, shrug
  - 인사: bow15, bow30, bow45, wave, wave2
  - 손: hands, give, point, mouth (입 막기), clap, fist, pat (쓰다듬기), card (가루타 치기), throw (콩 던지기), eat
  - 몸: jump, laugh, cry, sulk, shy, hug, pray, dance, cane (지팡이 걷기), sleep, stretch
  - 감정: grip_sleeve (소매 잡기), lean_in (다가가기), reach_miss (더듬다 빗나감), flinch_sound (소리에 움찔), look_away, crouch_bury (쪼그려 앉아 얼굴 파묻기)
- **소품**: cane (지팡이), gift (선물상자), card (명함), bag, karuta, phone, beans (콩), sparkler, tanzaku (단자쿠), bouquet (꽃다발)

## 5. 조연 캐릭터와 자동 연출

- **조연도 몸이 있어요.** 엄마·아빠·하나·미야코·선생님·반친구·선배아빠·하루토는 처음 말할 때 로우폴리 캐릭터로 나타나서, 말하는 사람 쪽을 보고 손짓해요. 그 장면(배경)이 바뀌면 사라져요.
  - 대사가 `(복도에서)`, `(전화)`, `(SNS)`, `(멀리서 …)`, `(문 너머)`처럼 시작하면 몸 없이 목소리만 나와요.
- **서술(나:)에 쓴 행동을 캐릭터가 실제로 해요.** "스즈가 허리를 끌어안았다" → 둘이 다가가서 안기, "고개를 끄덕였다" → 끄덕, "귓불이 빨개졌다" → 홍조, "주저앉아 얼굴을 파묻었다" → 쪼그려 앉기 등.
  - 누가 하는지는 문장 속 "스즈가/스즈는/나는/내가/엄마가…"로 정해요. 주어가 없으면 바로 앞 서술의 주어를 이어받아요.
  - 대사에 `[표정/동작]`을 직접 쓰거나 바로 앞에 `@동작`·`@표정`을 쓰면 그게 먼저예요. 자동 연출은 빈 곳만 채워요.
- 대사도 `!!`, `?`, `미안`, `고마워`, `에헤헤` 같은 말투를 보고 표정·동작이 붙어요 (직접 쓴 게 없을 때만).

## 6. 일본어 후리가나·발음 데이터

일본어 대사를 새로 쓰거나 고치면, 후리가나(요미가나)와 한글 발음을 다시 만들어 줘야 정확해요. 안 하면 예전 방식(작은 사전)으로 대충 읽어요.
```
node tools/jp_script.js build
node tools/jp_script.js texts
python3 tools/jp_yomi.py        # 처음 한 번: pip install fugashi unidic-lite
```
